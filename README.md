## Run
Open a terminal in the repository root. Run a task using its script path. For package tasks, run from the task folder:

```powershell
cd AT4_CO4/Task01
python task01_mess_bills.py
```

Repeat with the relevant task folder and script name. For Task 5, run `python main.py` from `AT4_CO4/Task05`. For Task 6, run `python main.py` from `AT4_CO4/Task06`.
